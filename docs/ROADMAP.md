- [x] برمجة مسارات إدارة السير الذاتية (CV CRUD API):
  - إنشاء، تعديل، حذف، جلب، وتكرار السيرة الذاتية.

### 📍 المرحلة 5: واجهة لوحة التحكم وبناء الـ CV (Dashboard & Builder)
- [x] صفحات المصادقة (Login / Register) مع زر الدخول السريع التجريبي بنقرة واحدة (Demo Login).
- [x] لوحة التحكم الرئيسية (Dashboard):
  - بطاقات الإحصائيات (عدد السير، رصيد الذكاء الاصطناعي، حالة الباقة).
  - قائمة السير الذاتية المحفوظة مع إمكانية التعديل، التكرار، والحذف (مربوطة بنظام التنبيهات المخصص).
  - مودال استيراد السيرة الذاتية ورفع ملف PDF بالذكاء الاصطناعي.
- [x] معالج إدخال السيرة الذاتية (Multi-step CV Builder):
  - شريط تحكم علوي يتيح فتح معرض القوالب، مغير ألوان الثيم، وحفظ السيرة الذاتية.
  - 7 تبويبات إدخال منظمة:
    1. 👤 البيانات الشخصية والاتصال مع زر التحسين بالذكاء الاصطناعي.
    2. 💼 الخبرات الوظيفية مع إضافة وحذف ديناميكي.
    3. 🎓 البيانات التعليمية مع إضافة وحذف ديناميكي.
    4. ⚡ المهارات واللغات (مع قاعدة اللغتين الأساسيتين المجانيتين ونظام ترقية Pro للغة الإضافية).
    5. 🏆 الشهادات والدورات التدريبية.
    6. 🚀 المشاريع والإنجازات.
    7. 👥 المراجع والمعرّفون (References).
- [x] شاشة المعاينة الحية المباشرة (Live CV Preview) جنباً إلى جنب مع الإدخال (Split Screen).
- [x] دعم تصدير وطباعة السيرة الذاتية كـ PDF عالي الدقة (A4 Vector Print) يدعم الحروف العربية المتصلة 100% وعزل النصوص ثنائية الاتجاه `<bdi>`.
