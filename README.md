## ⚡ خطوات التشغيل السريعة
1. **التشغيل المباشر بنقرة واحدة (Windows)**:
   - قم بتشغيل الملف `run-project.bat` وسيقوم بتشغيل الباك إند والفرونت إند معاً تلقائياً.

2. **التشغيل اليدوي عبر موجه الأوامر**:
   - **الخادم (Backend)**:
     ```bash
     cd server
     npm start
     ```
   - **الواجهة الأمامية (Frontend)**:
     ```bash
     cd client
     npm start
     ```
   - افتح المتصفح على: `http://localhost:4200`
